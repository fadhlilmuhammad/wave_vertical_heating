# wave_vertical_heating

```bash
wave_vertical_heating/
├── analysis
│   ├── example.ipynb
│   └── figures
│       └── .figures
├── .copier-answers.yml
├── data -> /g/data/v46/$USER/wave_vertical_heating/data
│   ├── derived
│   └── raw
│       └── DO_NOT_EDIT
├── .envrc
├── .git
├── .gitignore
├── README.md
├── requirements.txt
├── src
│   └── wave_vertical_heating
│       ├── __init__.py
│       └── sample_fun.py
└── tests
    └── wave_vertical_heating
        └── test_sample_fun.py
```

The data folder may not be present in the repository but instructions and or documentation are provided.
